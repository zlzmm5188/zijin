## 🔧 调整方法

### 方法1: 在Agent设置中调整（推荐）

1. **打开Agent设置**
   - 点击Cursor右上角设置图标
   - 或使用快捷键 `⌘,` (Mac) / `Ctrl+,` (Windows/Linux)
   - 找到 "Agent" 或 "AI" 设置

2. **修改Model设置**
   - 找到 "Model" 选项（当前显示为 "Auto"）
   - 点击右侧的下拉箭头
   - 选择以下高级模型之一：
     - **O3** (最高级别，最强大)
     - **Claude 4 Opus** (最高级别，推理能力强)
     - **GPT-4.1** (高级，速度快)
     - **Gemini 2.5 Pro** (高级，主动性强)

3. **保存设置**
   - 点击 "Done" 按钮
   - 设置立即生效

---

### 方法2: 在AI输入框中临时选择

1. **打开AI对话**
   - 使用快捷键 `⌘I` (Mac) / `Ctrl+I` (Windows/Linux)
   - 或点击AI图标

2. **选择模型**
   - 在AI输入框下方找到模型选择下拉菜单
   - 选择您想要的高级模型
   - 此选择仅对当前对话有效

## ⚙️ 配置文件方式（高级）

如果需要在配置文件中设置，可以尝试：

### 配置文件位置
```
~/.cursor-server/data/Machine/settings.json
```

### 配置示例
```json
{
    "cursor.ai.model": "o3",
    "cursor.ai.autoRun": true,
    "cursor.ai.keybinding": "cmd+i"
}
```

**注意**: 配置文件中的键名可能因Cursor版本而异，建议优先使用GUI设置。

## 💡 使用建议

### 何时使用最高级别模型？

✅ **推荐使用O3或Claude 4 Opus**:
- 处理非常复杂的技术问题
- 需要深度推理和算法设计
- 架构设计和系统规划
- 解决疑难bug

⚠️ **注意事项**:
- O3速度较慢，适合复杂任务
- 高级模型消耗更多资源
- 简单任务可能不需要最高级别

### 何时使用Auto模式？

✅ **推荐使用Auto**:
- 日常开发任务
- 不确定任务复杂度时
- 需要平衡性能与成本
- 希望系统自动优化
