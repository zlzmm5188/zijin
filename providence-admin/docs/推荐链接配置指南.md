## ⚙️ 配置步骤

### 1️⃣ CloudFlare DNS配置

登录CloudFlare账户，为 `frevix.top` 域名添加泛解析：

```
类型：A
名称：*
内容：服务器IP地址
代理：已代理（橙色云朵）
TTL：自动
```

### 2️⃣ Nginx配置

在宝塔面板中，修改前台站点的Nginx配置：

```nginx
server {
    listen 80;
    listen 443 ssl http2;
    server_name qiantai.frevix.top *.frevix.top;

    # SSL证书配置
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    root /www/wwwroot/providence-admin;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 3️⃣ 前端自动识别二级域名

在注册页面添加自动识别逻辑：

```javascript
// 自动从二级域名提取推荐码
function getInviteCodeFromDomain() {
    const hostname = window.location.hostname;

    // 匹配 [推荐码].frevix.top 格式
    const match = hostname.match(/^([^.]+)\.frevix\.top$/);

    if (match && match[1] !== 'qiantai' && match[1] !== 'houtai' && match[1] !== 'api') {
        return match[1].toUpperCase(); // 返回推荐码
    }

    // 兼容URL参数
    const urlParams = new URLSearchParams(window.location.search);
    return urlParams.get('invite') || '';
}

// 页面加载时自动填充邀请码
document.addEventListener('DOMContentLoaded', function() {
    const inviteCode = getInviteCodeFromDomain();
    if (inviteCode) {
        const inviteInput = document.getElementById('invite_code');
        if (inviteInput) {
            inviteInput.value = inviteCode;
            inviteInput.readOnly = true; // 锁定邀请码
        }
    }
});
```

#### 方式2：SQL查询

```sql
-- 查看 G138688 的直接下线
SELECT
    id,
    username,
    uid AS invite_code,
    vip_level,
    created_at
FROM users
WHERE parent_id = 1  -- G138688的用户ID
ORDER BY created_at DESC;

-- 查看完整推荐树（递归查询）
WITH RECURSIVE team_tree AS (
    -- 起点：G138688
    SELECT id, username, uid, parent_id, 1 AS level
    FROM users
    WHERE id = 1

    UNION ALL

    -- 递归：查找下级
    SELECT u.id, u.username, u.uid, u.parent_id, t.level + 1
    FROM users u
    INNER JOIN team_tree t ON u.parent_id = t.id
)
SELECT
    level AS '层级',
    username AS '用户名',
    uid AS '推荐码',
    CONCAT('https://', uid, '.frevix.top') AS '推广链接'
FROM team_tree
ORDER BY level, id;
```
