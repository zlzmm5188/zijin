## 后端接口

### 1. 创建支付订单
**接口**: `POST /index.php/pay/create`

**请求参数**:
```json
{
  "amount": 100.00,
  "payment_method": "wechat",  // 或 "alipay"
  "return_url": "https://copla.top/recharge.html"  // 可选
}
```

**响应示例**:
```json
{
  "code": 1,
  "msg": "支付订单创建成功",
  "data": {
    "order_no": "RCH20241117123456",
    "amount": 100.00,
    "payment_method": "wechat",
    "channel": "S02",
    "channel_name": "微信扫码",
    "pay_url": "https://...",
    "qr_code": "data:image/png;base64,...",
    "expire_time": "2024-11-17 12:45:00",
    "gateway_order_no": "GW20241117123456"
  }
}
```

### 2. 查询支付订单
**接口**: `GET /index.php/pay/query?order_no=RCH20241117123456`

**响应示例**:
```json
{
  "code": 1,
  "msg": "查询成功",
  "data": {
    "order_no": "RCH20241117123456",
    "amount": 100.00,
```

### 3. 支付回调通知
**接口**: `POST /index.php/pay/notify`

此接口由支付网关自动调用，无需前端调用。

## 签名算法

签名生成规则：
1. 移除 `sign` 字段
2. 按键名排序
3. 构建签名字符串：`key1=value1&key2=value2&...&key=API密钥`
4. MD5加密并转大写

## 前端调用示例

```javascript
// 创建支付订单
async function createPayment(amount, paymentMethod) {
  const response = await fetch('https://apis.copla.top/index.php/pay/create', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'token': localStorage.getItem('providence_token')
    },
    body: JSON.stringify({
      amount: amount,
      payment_method: paymentMethod, // 'wechat' 或 'alipay'
      return_url: window.location.href
    })
  });

  const result = await response.json();
  if (result.code === 1) {
    // 显示支付二维码或跳转支付页面
    if (result.data.qr_code) {
      // 显示二维码
      showQRCode(result.data.qr_code);
    } else if (result.data.pay_url) {
      // 跳转支付页面
      window.location.href = result.data.pay_url;
    }

    // 轮询查询订单状态
    pollOrderStatus(result.data.order_no);
  }
}

// 查询订单状态
async function queryOrder(orderNo) {
  const response = await fetch(`https://apis.copla.top/index.php/pay/query?order_no=${orderNo}`, {
    headers: {
      'token': localStorage.getItem('providence_token')
    }
  });

  return await response.json();
}

// 轮询订单状态
function pollOrderStatus(orderNo) {
  const interval = setInterval(async () => {
    const result = await queryOrder(orderNo);
    if (result.code === 1 && result.data.status === 1) {
      clearInterval(interval);
      showToast('支付成功');
      // 刷新余额或跳转
      window.location.reload();
    }
  }, 3000); // 每3秒查询一次

  // 30秒后停止轮询
  setTimeout(() => clearInterval(interval), 30000);
}
```

## 注意事项

1. **金额限制**: 微信支付 100-3000元，支付宝支付 100-20000元
2. **回调IP**: 需要在支付网关后台配置回调IP为 `23.94.207.16`
3. **签名验证**: 所有请求和回调都会进行签名验证
4. **订单号**: 商户订单号必须唯一，格式为 `RCH` + 时间戳 + 随机数
5. **超时处理**: 支付订单通常有30分钟有效期，超时后需要重新创建
