# 收益计算规则 v2.0（重要变更）

**更新时间：2024-11-10**  
**变更原因：取消年化概念，改为周期收益**

---

## ⚠️ 重要变更

### 删除的概念

- ❌ `total_rate` - 删除年化概念
- ❌ 日利率 - 不再使用
- ❌ 年化收益率 - 完全删除

### 新的计算方式

**所有收益率均为周期收益率**

---

## 💰 新收益计算公式

### 核心公式

```
周期收益 = 投资金额 × (基础收益率 + VIP额外收益率) / 100
总金额 = 投资金额 + 周期收益
日均收益 = 周期收益 / 周期天数
```

### 字段说明

| 字段 | 含义 | 示例 |
|------|------|------|
| `cycle_days` | 项目周期天数 | 30 |
| `base_rate` | 基础收益%（整个周期） | 4.5 (表示4.5%) |
| `vip_extra_rate` | VIP额外收益%（整个周期） | 0.3 (表示+0.3%) |
| `profit` | 周期总收益 | 2560 |
| `total` | 本金+收益 | 12560 |
| `daily_profit` | 日均收益 | 85.33 |

---

## �� 示例计算

### 案例1：普通用户投资

```
投资金额: 10,000
项目周期: 30天
基础收益率: 4.5%（30天）
VIP额外: 0%（VIP0）

计算:
周期收益 = 10000 × (4.5 + 0) / 100 = 450
总金额 = 10000 + 450 = 10,450
日均收益 = 450 / 30 = 15
```

### 案例2：VIP用户投资

```
投资金额: 10,000
项目周期: 30天
基础收益率: 4.5%（30天）
VIP额外: 0.3%（VIP1）

计算:
周期收益 = 10000 × (4.5 + 0.3) / 100 = 480
总金额 = 10000 + 480 = 10,480
日均收益 = 480 / 30 = 16
```

## 🔌 API接口变更

### 项目详情 GET /fund/project/detail

**新增字段：**
```json
{
  "cycle_days": 30,          // 周期天数
  "base_rate": 4.5,          // 基础收益%（整个周期）
  "vip_extra_rate": 0        // VIP额外收益%（用户当前VIP）
}
```

**删除字段：**
- ~~`daily_rate`~~ - 删除
- ~~`total_return_rate`~~ - 删除
- ~~`annual_rate`~~ - 删除

### 收益计算 POST /fund/project/calculate

**请求：**
```json
{
  "project_id": 1,
  "amount": 10000
}
```

**响应：**
```json
{
  "code": 1,
  "message": "计算成功",
  "data": {
    "profit": 2560,        // 周期总收益
    "total": 12560,        // 本金+收益
    "daily_profit": 85.33  // 日均收益
  }
}
```
