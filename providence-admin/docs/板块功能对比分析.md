**数据库查询示例**：
```sql
-- 今日新增用户
SELECT COUNT(*) FROM users
WHERE DATE(created_at) = CURDATE();

-- 今日投资
SELECT COALESCE(SUM(invest_amount), 0) FROM invest_orders
WHERE DATE(created_at) = CURDATE();

-- 待审核数量
SELECT COUNT(*) FROM user_kyc WHERE status = 0;
SELECT COUNT(*) FROM recharge_records WHERE status = 0;
SELECT COUNT(*) FROM withdraw_records WHERE status = 0;
```

## 🔧 技术实施建议

### 代码结构规范

```
/api/admin/
  ├─ dashboard.php      # Dashboard数据API
  ├─ projects/
  │   ├─ list.php       # 项目列表
  │   ├─ create.php     # 添加项目
  │   ├─ update.php     # 编辑项目
  │   ├─ delete.php     # 删除项目
  │   └─ config.php     # 项目配置
  ├─ users/
  │   ├─ list.php       # 用户列表
  │   ├─ detail.php     # 用户详情
  │   ├─ reset-pwd.php  # 重置密码
  │   └─ toggle.php     # 状态切换
  ├─ orders/
  │   ├─ list.php       # 订单列表
  │   └─ detail.php     # 订单详情
  └─ finance/
      ├─ stats.php      # 财务统计
      ├─ export.php     # 导出数据
      └─ report.php     # 财务报表
```
