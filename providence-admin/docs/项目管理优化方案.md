已有字段（✅ 完善）:
- 基础信息：id, project_code, title, subtitle, description

## 🔧 需要实现的API

### 1. 项目列表API
```
GET /api/admin/projects
参数：
  - page: 页码
  - limit: 每页数量
  - category: 分类筛选
  - currency: 币种筛选
  - status: 状态筛选
  - keyword: 搜索关键词

返回：
{
  "code": 1,
  "message": "获取成功",
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "limit": 20
  }
}
```

### 2. 添加项目API
```
POST /api/admin/project/create
参数：
  - title: 项目名称
  - subtitle: 副标题
  - category: 分类
  - currency: 币种
  - cycle_days: 周期
  - base_rate: 基础利率
  - added_rate: 活动加息
  - gift_rate: 赠送利率
  - min_invest: 最低投资
  - max_invest: 最高投资
  - total_quota: 总额度
  - manager_id: 项目经理ID
  - description: 描述
  - cover_image: 封面图
  - payment_type: 支付方式限制
  - vip_min: 最低VIP要求
  - need_referral: 需要推荐人
  - team_member_required: 团队人数要求
  - mcount: 购买次数限制
  - is_index: 首页显示
  - sort: 排序权重

返回：
{
  "code": 1,
  "message": "添加成功",
  "data": {
    "id": 123,
    "project_code": "PRJ20241110001"
  }
}
```

### 3. 编辑项目API
```
POST /api/admin/project/update
参数：
  - id: 项目ID
  - (其他字段同添加)
```

### 4. 删除项目API
```
POST /api/admin/project/delete
参数：
  - id: 项目ID
```

### 5. 切换首页显示API
```
POST /api/admin/project/toggle-index
参数：
  - id: 项目ID
  - is_index: 0|1
```

### 6. 切换状态API
```
POST /api/admin/project/toggle-status
参数：
  - id: 项目ID
  - status: 0|1
```

### 7. 更新排序API
```
POST /api/admin/project/update-sort
参数：
  - id: 项目ID
  - sort: 排序权重
```

## 📊 数据流程

### 添加项目流程
```
用户填写表单
    ↓
前端验证
    ↓
调用API: /api/admin/project/create
    ↓
后端验证（字段、权限）
    ↓
自动生成project_code
    ↓
计算total_rate (base_rate + added_rate + gift_rate)
    ↓
初始化统计字段
    ↓
插入数据库
    ↓
记录审计日志
    ↓
返回成功 + 项目ID
    ↓
前端跳转到项目列表
```

### 编辑项目流程
```
用户点击编辑
    ↓
加载项目数据
    ↓
填充到表单
    ↓
用户修改
    ↓
提交更新API
    ↓
version字段+1（版本控制）
    ↓
更新数据库
    ↓
清除相关缓存
    ↓
记录审计日志
    ↓
返回成功
```
