## 📊 数据库升级

### 新增字段（invest_projects表）

```sql
ALTER TABLE invest_projects
ADD COLUMN is_index TINYINT DEFAULT 0 COMMENT '首页显示:0否1是',
ADD COLUMN sort INT DEFAULT 0 COMMENT '排序权重(越大越靠前)',
ADD COLUMN payment_type TINYINT DEFAULT 0 COMMENT '支付方式:0不限1仅USDT2仅CNY',
ADD COLUMN vip_min TINYINT DEFAULT 0 COMMENT '最低VIP等级要求',
ADD COLUMN need_referral TINYINT DEFAULT 0 COMMENT '需要推荐人:0否1是',
ADD COLUMN team_member_required INT DEFAULT 0 COMMENT '团队人数要求',
ADD COLUMN mcount INT DEFAULT 0 COMMENT '购买次数限制:0不限';
```

### 索引优化

```sql
ALTER TABLE invest_projects ADD INDEX idx_is_index (is_index);
ALTER TABLE invest_projects ADD INDEX idx_sort (sort);
ALTER TABLE invest_projects ADD INDEX idx_payment_type (payment_type);
ALTER TABLE invest_projects ADD INDEX idx_vip_min (vip_min);
```
