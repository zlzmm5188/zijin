✅ 充值审核（recharge.html）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能:
✓ 显示充值申请列表
✓ 凭证图片数量显示（如：2张图片 🖼️）
✓ 点击查看凭证图片（大图预览）
✓ 点击"审核"按钮进入审核流程
✓ 审核界面显示：
  - 订单信息
  - 凭证图片预览
  - 审核备注输入
  - 通过/拒绝按钮

审核流程:
1. 点击"审核"按钮
2. 弹出模态框显示详情
3. 查看用户上传的凭证图片
4. 填写审核意见（可选）
5. 点击"通过"或"拒绝"

✅ 提现审核（withdraw.html）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

功能:
✓ 显示提现申请列表
✓ 显示银行卡/USDT地址信息
✓ 4种状态：
  - 待审核 → 可通过/拒绝
  - 已通过 → 可确认打款
  - 已拒绝 → 已完成
  - 已打款 → 已完成

✓ 审核界面显示：
  - 订单完整信息
  - 提现金额、手续费、实际到账
  - 银行卡/钱包地址
  - 审核备注
  - 打款凭证上传（已通过状态）

审核流程:
1. 待审核 → 点击"通过"或"拒绝"
2. 已通过 → 点击"确认打款"
   - 可上传打款凭证截图
   - 确认后订单状态变为"已打款"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📸 图片预览功能

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

充值凭证:
• 用户上传1-3张凭证图片
• 列表显示图片数量
• 点击可查看大图
• 支持多张图片滚动查看

提现打款:
• 审核通过后可上传打款凭证
• 打款凭证作为财务记录
• 用户可在前台查看打款凭证
