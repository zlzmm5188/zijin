### 查询创始人下级用户数量

### 查询创始人下级用户列表
```sql

    u.id,
    u.uid AS '邀请码',
    u.username AS '用户名',
    u.phone AS '手机号',

    u.total_invest AS '累计投资',

```

### 查询创始人下级用户充值记录
```sql
SELECT
    r.id,
    r.order_no AS '订单号',
    u.uid AS '用户邀请码',
    u.username AS '用户名',
    r.amount AS '充值金额',
    r.currency AS '币种',
    r.status AS '状态',
    r.created_at AS '充值时间'
FROM recharge_orders r
INNER JOIN users u ON r.user_id = u.id

```

### 查询创始人下级用户充值总额
```sql

    r.currency AS '币种',

    COUNT(*) AS '充值次数'

INNER JOIN users u ON r.user_id = u.id
WHERE u.parent_id = 1  -- 创始人账号ID

```
