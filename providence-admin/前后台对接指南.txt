🔧 宝塔面板配置步骤

【方案1：创建独立API站点 (推荐)】

1. 登录宝塔面板
2. 网站 → 添加站点
   - 域名: api.frevix.top
   - 根目录: /www/wwwroot/providence-admin/api
   - PHP版本: 8.2
   - 创建站点

3. 配置伪静态
   网站设置 → 伪静态 → 添加：
   
   if (!-e $request_filename) {
       rewrite ^/(.*)$ /index.php?$1 last;
   }

4. 配置SSL证书（生产环境必须）
   网站设置 → SSL → Let's Encrypt → 申请

5. 测试访问
   https://api.frevix.top/fund/project/all

【方案2：使用现有站点的子路径】

已在 houtai.frevix.top 配置中添加：

location ^~ /api {
    alias /www/wwwroot/providence-admin/api;
    index index.php;
    
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-82.sock;
        fastcgi_param SCRIPT_FILENAME $request_filename;
        include fastcgi_params;
    }
}
