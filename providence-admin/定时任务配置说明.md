# Providence 定时任务配置说明

**配置位置**: 宝塔面板 → 计划任务

---

## 📋 需要配置的定时任务

### 1. 每日收益发放

**执行时间**: 每天 00:01
**任务类型**: Shell脚本
**执行内容**:
```bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/daily-earnings.php
```

**功能说明**:
- 自动为所有运行中的投资订单发放每日收益
- 检查订单是否到期，到期后自动完成订单
- 记录收益流水到 `earnings_records` 表

---

### 2. VIP自动升级

**执行时间**: 每天 01:00
**任务类型**: Shell脚本
**执行内容**:
```bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/vip-upgrade.php
```

**功能说明**:
- 根据用户累计投资额自动升级VIP等级
- 只升级不降级
- 记录VIP升级日志

---

### 3. 团队奖励检测（可选）

**执行时间**: 每天 02:00
**任务类型**: Shell脚本
**执行内容**:
```bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/team-rewards.php
```

**功能说明**:
- 检测团队奖励条件
- 自动发放团队奖励
- 记录奖励流水

**注意**: 如果此文件不存在，可以暂时不配置

---

## 🔧 宝塔面板配置步骤

### 步骤1: 进入计划任务
1. 登录宝塔面板
2. 点击左侧菜单 "计划任务"
3. 点击 "添加计划任务"

### 步骤2: 配置每日收益发放
1. **任务类型**: 选择 "Shell脚本"
2. **任务名称**: 填写 "每日收益发放"
3. **执行周期**: 选择 "每天"
4. **执行时间**: 选择 "00:01"
5. **脚本内容**: 粘贴以下内容
```bash
#!/bin/bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/daily-earnings.php >> /www/wwwroot/xin.frevix.top/providence-admin/logs/cron-daily-earnings.log 2>&1
```
6. 点击 "添加"

### 步骤3: 配置VIP升级
1. **任务类型**: 选择 "Shell脚本"
2. **任务名称**: 填写 "VIP自动升级"
3. **执行周期**: 选择 "每天"
4. **执行时间**: 选择 "01:00"
5. **脚本内容**: 粘贴以下内容
```bash
#!/bin/bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/vip-upgrade.php >> /www/wwwroot/xin.frevix.top/providence-admin/logs/cron-vip-upgrade.log 2>&1
```
6. 点击 "添加"

### 步骤4: 配置团队奖励（如果文件存在）
1. **任务类型**: 选择 "Shell脚本"
2. **任务名称**: 填写 "团队奖励检测"
3. **执行周期**: 选择 "每天"
4. **执行时间**: 选择 "02:00"
5. **脚本内容**: 粘贴以下内容
```bash
#!/bin/bash
php /www/wwwroot/xin.frevix.top/providence-admin/cron/team-rewards.php >> /www/wwwroot/xin.frevix.top/providence-admin/logs/cron-team-rewards.log 2>&1
```
6. 点击 "添加"

## ✅ 验证配置

### 方法1: 手动执行测试
在宝塔面板的计划任务列表中，点击对应任务的 "执行" 按钮，查看执行结果。

### 方法2: 查看日志
定时任务的执行日志会保存在：
- `/www/wwwroot/xin.frevix.top/providence-admin/logs/cron-daily-earnings.log`
- `/www/wwwroot/xin.frevix.top/providence-admin/logs/cron-vip-upgrade.log`
- `/www/wwwroot/xin.frevix.top/providence-admin/logs/cron-team-rewards.log`

### 方法3: 检查数据库
- 检查 `earnings_records` 表是否有新的收益记录
- 检查 `users` 表的 `vip_level` 字段是否有更新

---

## ⚠️ 注意事项

1. **PHP路径**: 确保PHP路径正确，可以使用 `which php` 命令查看
2. **文件权限**: 确保定时任务文件有执行权限
3. **日志目录**: 确保日志目录存在且有写入权限
4. **数据库连接**: 确保数据库配置正确
5. **时区设置**: 确保服务器时区设置正确

---

## 🔍 故障排查

### 问题1: 定时任务不执行
- 检查宝塔面板的计划任务是否启用
- 检查PHP路径是否正确
- 检查文件权限

### 问题2: 执行失败
- 查看日志文件了解错误信息
- 检查数据库连接配置
- 检查表结构是否正确

### 问题3: 收益未发放
- 检查订单状态是否为 `running`
- 检查订单日期是否在有效期内
- 检查是否已发放过（避免重复发放）

---

**配置完成后，系统将自动执行这些定时任务，无需人工干预。**
