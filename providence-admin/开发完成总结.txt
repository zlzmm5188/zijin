🚀 使用说明

【1. 配置Nginx】
在宝塔面板中添加location配置:

location ^~ /providence-admin/api {
    alias /www/wwwroot/providence-admin/api;
    index index.php;
    
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-74.sock;
        fastcgi_param SCRIPT_FILENAME $request_filename;
        include fastcgi_params;
    }
}

【2. 访问测试页面】
http://72.60.234.87/providence-admin/api/test.php

【3. 访问管理后台】
http://72.60.234.87/providence-admin/admin/login.html

【4. 前台对接API】
修改前台 config.js:
baseURL: 'http://72.60.234.87/providence-admin/api'

【5. 配置定时任务】
在宝塔面板 -> 计划任务中添加:

任务1: 每日收益发放 (每天00:01)
php /www/wwwroot/providence-admin/cron/daily-earnings.php

任务2: VIP自动升级 (每天01:00)
php /www/wwwroot/providence-admin/cron/vip-upgrade.php
