## 🔧 技术实现

### project-detail.js核心逻辑

```javascript
// 1. 获取项目ID
const projectId = getUrlParam('id');

// 2. 调用API
const res = await fetch(`${API_BASE}/fund/project/detail?id=${id}`);
const data = await res.json();

// 3. 更新页面
if (data.code === 1 && data.data) {
    const p = data.data;
    document.getElementById('cycle').textContent = p.cycle_days + '天';
    document.getElementById('rateVip').textContent = p.vip_rate + '%';
    document.getElementById('maxAmt').textContent = p.max_invest;
    document.getElementById('minAmt').textContent = p.min_invest;
}
```

### ribao.html核心逻辑

```javascript
// 1. 加载日利宝数据
const ribaoRes = await fetch(`${API_BASE}/user/ribao/info`, {
    headers: { token: token }
});
const ribaoData = await ribaoRes.json();

// 2. 更新显示
if (ribaoData.code === 1 && ribaoData.data) {
    ribaoBalance = parseFloat(ribaoData.data.ribao_balance || 0);
    document.getElementById(totalAmount).textContent = 
        ribaoBalance.toLocaleString(zh-CN, { minimumFractionDigits: 2 });
    document.getElementById(yesterdayProfit).textContent = 
        parseFloat(ribaoData.data.yesterday_profit || 0).toFixed(2);
}
```
