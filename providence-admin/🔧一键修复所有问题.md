# Providence 后台问题一键修复

**问题：** API请求404、CSS找不到

**原因：** 宝塔站点根目录在`/admin/`下，访问`/api`和`/public`找不到

---

## ✅ 解决方案（宝塔面板配置）

### 步骤1：修改站点根目录（推荐）⭐

1. 登录宝塔面板
2. 网站 → 找到 `houtai.frevix.top`
3. 设置 → 网站目录
4. **修改运行目录**：
   ```
   原来: /www/wwwroot/providence-admin/admin
   改为: /www/wwwroot/providence-admin
   ```
5. 保存

6. **修改默认文档**：
   ```
   添加: admin/index.html
   ```

修改后访问路径：
- 后台首页: https://houtai.frevix.top/admin/index.html
- API: https://houtai.frevix.top/api/admin/stats.php ✅
- CSS: https://houtai.frevix.top/public/css/srs-design-system.css ✅

---

### 步骤2：或者添加nginx location配置

如果不想改根目录，在nginx配置文件添加：

```nginx
# API路径
location ^~ /api {
    alias /www/wwwroot/providence-admin/api;
    index index.php;
    
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-82.sock;
        fastcgi_param SCRIPT_FILENAME $request_filename;
        include fastcgi_params;
    }
}

# 静态资源路径
location ^~ /public {
    alias /www/wwwroot/providence-admin/public;
}
```

保存并重启nginx

---

## 🎯 推荐方案

**修改站点根目录为 `/www/wwwroot/providence-admin`**

这样：
- ✅ /admin/ 可以访问后台
- ✅ /api/ 可以访问API
- ✅ /public/ 可以访问静态文件
- ✅ 不需要改代码
