🌐 API接口
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 获取日历数据
   GET /providence/calendar-crawler.php?action=get&date=2025-10-17&type=data&region=all&importance=all
   
   参数：
   - action: get (获取数据)
   - date: 日期 (YYYY-MM-DD)
   - type: 类型 (data/event/holiday)
   - region: 地区 (all/cn/us/eu/jp/uk)
   - importance: 重要性 (all/high/medium/low)
   
   响应：
   {
     "code": 0,
     "message": "success",
     "data": {
       "events": [...],
       "total": 4,
       "date": "2025-10-17",
       "updateTime": "2025-10-17 12:34:39"
     }
   }

2. 手动触发采集
   GET /providence/calendar-crawler.php?action=crawl&force=1
   
   响应：
   {
     "code": 0,
     "message": "采集成功",
     "data": {...},
     "count": 10
   }

问题：数据不更新
解决：
  1. 检查定时任务: crontab -l
  2. 查看日志: tail /tmp/calendar-cron.log
  3. 手动运行: php cron-update-calendar.php
  4. 检查权限: ls -l data/calendar-data.json

问题：页面加载空白
解决：
  1. 查看浏览器控制台
  2. 检查数据文件: cat data/calendar-data.json
  3. 测试API: curl calendar-crawler.php?action=get
  4. 强制刷新: Ctrl+Shift+R

问题：API采集失败
解决：
  1. 检查网络连接
  2. 查看错误日志
  3. 更换数据源或使用补充数据
  4. 调整采集频率
