🌐 API接口
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 获取课程数据
   GET /providence/education-crawler.php?action=get&category=all
   
   参数：
   - action: get (获取数据)
   - category: 分类 (all/basic/intermediate/advanced)
   
   响应：
   {
     "code": 0,
     "message": "success",
     "data": {
       "courses": [...],
       "total": 24,
       "updateTime": "2025-10-17 12:57:15"
     }
   }

2. 手动触发采集
   GET /providence/education-crawler.php?action=crawl&force=1
   
   响应：
   {
     "code": 0,
     "message": "采集成功",
     "count": 24,
     "updateTime": "2025-10-17 12:57:15"
   }

问题：数据不更新
解决：
  1. 检查定时任务: crontab -l
  2. 查看日志: tail /tmp/education-cron.log
  3. 手动运行: php cron-update-education.php
  4. 检查权限: ls -l data/education-data.json

问题：页面加载空白
解决：
  1. 查看浏览器控制台
  2. 检查数据文件: cat data/education-data.json
  3. 测试API: curl education-crawler.php?action=get
  4. 强制刷新: Ctrl+Shift+R

问题：采集失败
解决：
  1. 检查网络连接
  2. 查看错误日志
  3. 会自动使用备用数据
  4. 数据已本地化，不依赖外部
