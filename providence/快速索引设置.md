# 🚀 Cursor 代码库索引 - 快速设置指南

## ⚡ 最快方法（3步完成）

### 步骤1: 打开命令面板
```
按 Cmd/Ctrl + Shift + P
```

### 步骤2: 输入索引命令
```
输入：index codebase
```

### 步骤3: 选择并执行
```
选择：Codebase: Index Codebase
按回车执行
```

**等待 1-2 分钟，看到 "✓ Codebase indexed" 即完成！**

---

## 🎯 或者点击提示（更简单）

如果看到右下角提示：
```
"Codebase not indexed"
→ 点击 "Start indexing - Docs"
→ 等待完成
```

## 🔧 如果索引失败

### 方法1: 重启 Cursor
```
关闭 Cursor → 重新打开
→ 自动触发索引
```

### 方法2: 清除并重新索引
```
1. Cmd/Ctrl + Shift + P
2. 输入：clear index
3. 选择：Codebase: Clear Index
4. 重新执行索引命令
```

### 方法3: 检查设置
```
1. Cmd/Ctrl + , 打开设置
2. 搜索：codebase
3. 确保 "Enable Codebase Indexing" 已勾选
4. 确保 "Index on startup" 已勾选
```
