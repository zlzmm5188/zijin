# 🔌 Cursor/VS Code 推荐插件列表

> **重要说明**：这些是编辑器插件，安装在您的 Cursor 编辑器中，**不需要在服务器上安装**。

---

## ⭐ 必装插件（强烈推荐）

### 1. **PHP Debug** ✅ 已安装
- **插件ID**: `xdebug.php-debug`
- **用途**: PHP 调试，断点调试 PHP 代码
- **状态**: ✅ 已安装

### 2. **PHP Intelephense**
- **插件ID**: `bmewburn.vscode-intelephense-client`
- **用途**: PHP 代码补全、语法检查、跳转定义
- **为什么需要**: 提供智能代码补全和错误检查

### 3. **PHP IntelliSense**
- **插件ID**: `felixfbecker.php-intellisense`
- **用途**: PHP 代码补全和语法高亮
- **为什么需要**: 增强 PHP 开发体验

## 🎨 前端开发插件

### 4. **ESLint**
- **插件ID**: `dbaeumer.vscode-eslint`
- **用途**: JavaScript 代码检查和自动修复

### 6. **Auto Rename Tag**
- **插件ID**: `formulahendry.auto-rename-tag`
- **用途**: 自动重命名配对的 HTML 标签
- **为什么需要**: 您有 92 个 HTML 文件，编辑时非常方便

### 7. **CSS Peek**

- **用途**: 在 HTML 中快速查看 CSS 定义
- **为什么需要**: 快速定位样式定义

## 🚀 快速安装方法

### 方法1: 通过命令面板安装

1. 按 `Cmd/Ctrl + Shift + P`
2. 输入：`Extensions: Install Extensions`
3. 搜索插件名称或 ID
4. 点击安装

### 方法2: 通过扩展市场安装

1. 点击左侧扩展图标（或按 `Cmd/Ctrl + Shift + X`）
2. 搜索插件名称或 ID
3. 点击安装

## ⚙️ 推荐配置（settings.json）

安装插件后，建议添加以下配置：

```json
{
  // PHP 配置
  "php.validate.executablePath": "/usr/bin/php",
  "php.suggest.basic": false,

  // ESLint 配置
  "eslint.enable": true,
  "eslint.validate": [
    "javascript",
    "javascriptreact"
  ],

  // Prettier 配置
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[javascript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[html]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[css]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },

  // 文件关联
  "files.associations": {
    "*.php": "php",
    "*.sh": "shellscript"
  }
}
```

## 📝 注意事项

1. **这些插件只安装在编辑器**，不需要在服务器上安装
2. **PHP Debug** 需要服务器上安装 Xdebug 扩展（如果还没安装）
3. **ESLint** 可能需要项目根目录有 `.eslintrc` 配置文件
4. **Prettier** 可能需要项目根目录有 `.prettierrc` 配置文件
