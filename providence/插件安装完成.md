## 🚀 下一步操作

### 1. 重启 Cursor（推荐）

安装完成后，建议重启 Cursor 以确保所有插件正常工作：

```
关闭 Cursor → 重新打开
```

### 2. 配置插件设置

建议在设置中添加以下配置（`Cmd/Ctrl + ,`）：

```json
{
  // 格式化配置
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",

  // ESLint 配置
  "eslint.enable": true,
  "eslint.validate": ["javascript", "javascriptreact"],

  // PHP 配置
  "php.validate.executablePath": "/usr/bin/php",
  "php.suggest.basic": false
}
```

### 3. 验证插件工作

#### PHP Intelephense
- 打开任意 `.php` 文件
- 输入代码时应该看到智能补全提示

#### ESLint
- 打开任意 `.js` 文件
- 如果有语法错误，会显示红色波浪线

#### Prettier
- 保存文件时应该自动格式化
- 或按 `Shift + Alt + F` 手动格式化

#### Error Lens
- 打开有错误的文件
- 错误会直接显示在代码行内
