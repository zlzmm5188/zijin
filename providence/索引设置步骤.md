# 🔧 Cursor 索引设置 - 详细步骤

## ⚠️ 如果命令面板没有"Index Codebase"命令

### 方法1: 通过设置界面启用（推荐）

#### 步骤1: 打开设置
```
按 Cmd/Ctrl + , （逗号）
或者点击左下角齿轮图标 ⚙️ → Settings
```

#### 步骤2: 搜索索引设置
```
在设置搜索框输入：codebase indexing
```

#### 步骤3: 启用索引
找到以下设置并勾选：
- ✅ **Enable Codebase Indexing** - 启用代码库索引
- ✅ **Index on Startup** - 启动时自动索引

#### 步骤4: 重启 Cursor
```
关闭 Cursor → 重新打开
→ 会自动开始索引
```

---

### 方法2: 通过设置JSON文件配置

#### 步骤1: 打开设置JSON
```
按 Cmd/Ctrl + Shift + P
输入：Preferences: Open Settings (JSON)
```

#### 步骤2: 添加配置
我已经创建了 `.vscode/settings.json` 文件，包含完整配置。

如果设置JSON中没有，请添加：
```json
{
  "codebase.indexing.enabled": true,
  "codebase.indexing.onStartup": true
}
```

#### 步骤3: 保存并重启
```
保存文件 (Cmd/Ctrl + S)
关闭并重新打开 Cursor
```

---

### 方法3: 检查右下角提示

如果看到右下角有提示：
```
"Codebase not indexed"
"Results will get much better when Cursor understands your codebase"
```

**直接点击 "Start indexing - Docs"** 即可开始索引！

---

## 🔍 验证索引是否启动

### 查看索引状态

索引进行中时，右下角会显示：
```
"Indexing codebase... 45%"
或
"Indexing: 120/200 files"
```

索引完成后，提示会消失或显示：
```
"✓ Codebase indexed"
```

---

## 🎯 如果以上方法都不行

### 检查Cursor版本

1. 点击 **Help → About** 查看版本
2. 确保使用的是最新版本的 Cursor
3. 如果版本较旧，请更新到最新版本

### 手动触发索引

如果设置已启用但索引没有自动开始：

1. **确保已打开项目文件夹**
   ```
   File → Open Folder → 选择 /www/wwwroot/providence
   ```

2. **等待几秒钟**
   - Cursor 可能需要几秒钟来检测项目

3. **查看状态栏**
   - 右下角应该会显示索引进度

---

## ✅ 索引成功的标志

索引完成后，您应该能够：

1. **符号跳转**
   - 按住 `Cmd/Ctrl` 点击函数名 → 跳转到定义

2. **符号搜索**
   - 按 `Cmd/Ctrl + P`
   - 输入 `@函数名` → 找到函数位置

3. **AI 理解代码**
   - 问 AI："login.js 中的 handleLogin 函数做什么？"
   - AI 能准确回答
