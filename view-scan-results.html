⚠️ 返回码处理警告（200+ 处）

问题描述

许多文件只检查 code === 1 或 code === 200 其中一个， 但根据检查清单要求，应该同时检查两者：
// ❌ 错误做法 if (code === 1) { /* ... */ } // ❌ 错误做法 if (code === 200) { /* ... */ } // ✅ 正确做法 if (code === 1 || code === 200) { /* ... */ }

影响最严重的文件（前10个）

  • login.html - 登录页面
  • register.html - 注册页面
  • ribao.html - 日利宝
  • projects.html - 项目列表
  • withdraw.html - 提现
  • recharge.html - 充值
  • profile.html - 个人中心
  • bank-cards.html - 银行卡管理
  • points-exchange.html - 积分兑换
  • my-investments.html - 我的投资
