   Providence 登录问题解决方案
═══════════════════════════════════════

问题：无法登录，CORS错误
原因：浏览器缓存了旧的config.js文件

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【解决方法1】使用配置检测工具（最简单）

1. 访问: https://copla.top/test-config.html
2. 查看API地址是否显示: apis.copla.top
3. 如果显示 api.frevix.top，点击"清除缓存并刷新"
4. 等待页面自动跳转到登录页
5. 重新登录

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【解决方法2】手动清除缓存

Chrome/Edge浏览器：
1. 按 Ctrl + Shift + Delete
2. 选择"全部时间"
3. 勾选"缓存的图片和文件"
4. 点击"清除数据"
5. 关闭浏览器，重新打开

Safari浏览器：
1. 设置 → Safari
2. 清除历史记录与网站数据
3. 确认清除
4. 关闭Safari，重新打开

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【解决方法3】强制刷新（最快）

1. 打开登录页: https://copla.top/login.html
2. 按住 Ctrl + Shift + R（Mac: Cmd + Shift + R）
3. 连续按3-5次
4. 按F12打开控制台，检查是否显示:
   ✅ API地址已更新为: apis.copla.top

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【验证是否修复成功】

1. 打开登录页面
2. 按F12打开开发者工具
3. 在Console中输入:
   console.log(window.API_CONFIG.baseURL);
4. 应该显示: https://apis.copla.top
5. 如果还是 api.frevix.top，说明缓存还没清除
